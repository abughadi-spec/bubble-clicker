# فقاعة النقر (BubbleClicker)

تطبيق أندرويد يعرض فقاعة عائمة فوق أي لعبة أو تطبيق، يسجل نقراتك ويعيدها تلقائياً.

## التنزيل
افتح صفحة **Releases** في هذا المستودع ونزّل `BubbleClicker.apk`.

## الاستخدام
1. ثبّت التطبيق (اسمح بالتثبيت من مصادر غير معروفة إذا طلب).
2. افتح التطبيق ← «تفعيل الفقاعة» ← فعّل «فقاعة النقر» في إمكانية الوصول.
3. افتح اللعبة ← اضغط الفقاعة ← «تسجيل جديد» ← انقر الأماكن بالترتيب ← اضغط الشريط الأحمر للإنهاء.
4. اضغط الفقاعة ← «تشغيل». اضغط الفقاعة مرة ثانية للإيقاف.

> تنبيه: الأتمتة قد تخالف شروط بعض الألعاب وتسبب حظر الحساب.
